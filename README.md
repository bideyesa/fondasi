# Fondasi

A professional, formal, and minimalist UI component library designed for academic applications, with a specific focus on Hotumese SIMPATTI systems.

## Features

- 12+ ready-to-use UI components
- Built with vanilla JavaScript and CSS (no framework dependencies)
- Academic-focused design - formal, clean, and professional
- Responsive and accessible
- Customizable via CSS variables
- Lightweight and fast

## Installation

### CDN

After publishing to npm, use via jsDelivr or unpkg:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/fondasi@1.0.0/dist/fondasi.min.css">
<script src="https://cdn.jsdelivr.net/npm/fondasi@1.0.0/dist/fondasi.min.js"></script>
```

### NPM

```bash
npm install fondasi
```

### Download

Download the latest release from the [releases page](https://github.com/bideyesa/fondasi/releases).

## Quick Start

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Application</title>
    <link rel="stylesheet" href="fondasi.min.css">
</head>
<body>
    <button class="btn btn-primary">Click Me</button>

    <script src="fondasi.min.js"></script>
    <script>
        Fondasi.initComponents();
    </script>
</body>
</html>
```

## Use Case

Fondasi is specifically designed for academic applications like Hotumese SIMPATTI (Sistem Informasi Manajemen Perkuliahan dan Tugas Akhir):

- **Academic Documents** - Clean, professional forms for student data
- **Grade Management** - Clear table layouts for transcripts and scores
- **Course Registration** - Intuitive form interfaces
- **Administrative Panels** - Formal sidebar navigation for admin dashboards

## Components

- **Buttons** - Primary, secondary, ghost, danger variants
- **Form Elements** - Input, select, textarea, checkbox, radio
- **Card** - Content container
- **Badge** - Status indicators
- **Table** - Data tables with sorting
- **Tabs** - Tabbed navigation
- **Accordion** - Collapsible content
- **Modal** - Dialog windows
- **Drawer** - Slide-out panels
- **Dropdown** - Dropdown menus
- **Sidebar** - Navigation sidebar
- **Toast** - Notification messages
